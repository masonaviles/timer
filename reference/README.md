The original single-file timer this project generalized. It is the **behavioural baseline**:
every behaviour here is reproduced by the config-driven player (see
[docs/04-GHERKIN-SPEC.md](../docs/04-GHERKIN-SPEC.md) → *Feature: Player Parity*, all scenarios
green as of Phase 7).

Kept for historical reference only — **do not edit or ship it**. The live product is the
package in [`src/`](../src), demoed by [`../prototype.html`](../prototype.html) and the dev app.
